Q. What is type script 
TS is a superset of js that adds static typing and other feature to enhance js development.
It was developed by Microsoft on oct 1, 2012, and is now an open source project with a large community of contributors. 
-> TS is a superset of JS, which means any valid JS code is also valid TS code.

Note - 
-> TS catches errors at compile time instead of running, which makes debugging easier and reduces the likelihood of bugs in production.
-> (Disadvantages) - Browser doesn't support Ts. at the end we have to compile our TS code into js. like SASS ko ham compile karte the CSS me.
-> For easier to read, write and maintainable code we will use TS.

Installation -
-> npm install -g typescript

-> TS > tsc --version (typescript compiler) and then enter 
-> tsc --init (it will give us tsconfig.json file) then noEmitONError : true kar denge iss file me 
-> tsc index.ts => it will give us index.js file 

-> tsc --noEmitError index.ts (index.ts file me error na hane par hi hamari index.js file banegi else not)
